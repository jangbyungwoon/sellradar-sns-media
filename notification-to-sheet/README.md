# 안드로이드 주문 알림 → 구글 시트 자동 정리

```
[폰: 쇼핑몰 앱 알림] → MacroDroid(알림 감지) → 구글 Apps Script 웹앱 → 구글 시트
```

시트에 자동으로 생기는 탭:
- **주문알림**: 수신시각, 날짜, 쇼핑몰, 유형(신규주문/취소/반품/교환/배송/정산/구매확정), 상품명, 수량, 금액, 주문번호, 원문
- **일별요약**: 날짜·쇼핑몰별 신규주문 건수와 금액, 유형별 건수 (수식으로 자동 계산)

같은 알림이 여러 번 와도 10분 안에는 한 번만 기록됩니다.

---

## 1단계: 구글 시트 + 스크립트 (PC 권장, 5분)

1. 구글 시트를 새로 만듭니다 (예: `주문 알림 정리`).
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 지우고 이 폴더의 [`Code.gs`](./Code.gs) 내용을 전부 붙여넣습니다.
4. 맨 위의 `SECRET_TOKEN = 'CHANGE_ME_TO_RANDOM_STRING'`을 아무 긴 문자열로 바꿉니다 (예: `sr-8f3k2m9q`). 이 값은 아무에게도 공유하지 마세요.
5. 저장한 다음, 상단 함수 선택에서 **`setup`**을 고르고 **실행**을 누릅니다. 권한 요청이 나오면 승인합니다 ("확인되지 않은 앱" 경고가 나오면 고급 → 이동을 누르면 됩니다. 본인이 만든 스크립트라서 나오는 경고입니다).
6. 동작을 확인하려면 **`testInsert`**를 실행합니다. 시트에 샘플 주문 한 줄이 생기면 정상입니다 (확인 후 그 줄은 지워도 됩니다).
7. **배포 → 새 배포 → 유형: 웹 앱**을 선택합니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포하면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해 둡니다.

> 나중에 코드를 고치면 **배포 관리 → 수정 → 버전: 새 버전**으로 다시 배포해야 반영됩니다 (URL은 그대로 유지됩니다).

## 2단계: 폰에 MacroDroid 설정 (5분)

1. Play 스토어에서 **MacroDroid**를 설치합니다 (무료).
2. **매크로 추가**를 누릅니다.
3. **트리거**: `기기 이벤트 → 알림 → 알림 수신`
   - 앱 선택: **쇼핑몰 판매자 앱만** 체크합니다 (스마트스토어센터, 쿠팡 Wing, 11번가 셀러 등).
     카카오톡 같은 메신저를 넣으면 대화 속 "주문"이라는 말까지 주문으로 잡히니 넣지 마세요.
   - 텍스트 조건: "모두(Any)"
   - 알림 접근 권한을 요청하면 허용합니다.
4. **액션**: `연결/웹 → HTTP 요청`
   - URL: 1단계에서 복사한 웹 앱 URL
   - 메서드: **POST**
   - **쿼리 파라미터**에 아래 4개를 추가합니다 (값 칸에서 `...` 또는 매직 텍스트 버튼을 눌러 변수를 고르면 됩니다):

     | 이름 | 값 |
     |---|---|
     | `token` | 1단계에서 정한 SECRET_TOKEN |
     | `app` | 매직 텍스트 → **알림 앱 이름** |
     | `title` | 매직 텍스트 → **알림 제목** |
     | `text` | 매직 텍스트 → **알림 텍스트** |

   - 쿼리 파라미터로 넣으면 한글이나 특수문자 인코딩을 MacroDroid가 알아서 처리합니다.
5. 저장하고 매크로를 켭니다.
6. 배터리 최적화에서 MacroDroid를 **제외**합니다 (설정 → 앱 → MacroDroid → 배터리 → 제한 없음). 이걸 안 하면 폰이 잠겨 있을 때 알림을 놓칠 수 있습니다.

## 3단계: 확인

- 판매자 앱에서 테스트 알림이 오거나 실제 주문이 들어오면 몇 초 안에 시트의 `주문알림` 탭에 한 줄이 추가됩니다.
- MacroDroid 로그에 302 응답이나 리다이렉트 오류가 찍혀도 **시트에 줄이 생겼다면 정상**입니다. Apps Script 웹앱은 원래 응답을 리다이렉트로 돌려줍니다.

---

## 맞춤 설정 (`Code.gs` 상단)

| 항목 | 설명 |
|---|---|
| `KEEP_NON_ORDER` | `true`로 바꾸면 주문이 아닌 알림(문의 등)도 `기타알림` 탭에 저장합니다 |
| `SHOP_ALIASES` | 앱 이름을 보기 좋은 쇼핑몰 이름으로 바꾸는 규칙입니다. 쓰는 앱이 목록에 없으면 추가하세요 |
| `TYPE_RULES` | 유형 판별 키워드입니다. 위에 있는 규칙부터 먼저 적용됩니다 |

상품명, 수량, 금액, 주문번호는 알림 문구에서 패턴으로 뽑습니다. 앱마다 문구가 달라서 일부 칸이 비어 있을 수 있습니다. 실제 알림 원문(`알림내용` 열) 몇 개를 보내주시면 그 앱에 맞게 추출 규칙을 조정할 수 있습니다.

## 보안 메모
- 웹앱 URL과 토큰을 아는 사람만 시트에 기록할 수 있습니다. 둘 다 외부에 공유하지 마세요.
- 알림에는 고객 이름 같은 개인정보가 들어 있을 수 있으니, 시트 공유 범위를 본인으로 제한하세요.
